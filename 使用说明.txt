========================================
  自动点击器 AutoClickerTool  使用说明
========================================

【怎么打开】
双击 AutoClicker.exe 就可以用了。
(本文件夹里的其他东西不用管: src 是源码文件夹,
 config.json 是程序自己生成的设置存档, 不用动它们)

【这个软件能干什么】
1. 鼠标连点   - 自动反复点击鼠标, 可设定间隔/坐标/运行限制
2. 键盘连按   - 自动反复按某个键, 可点按或按住;
               点「点击按键」可以一次按多个键(比如 Shift+A)
3. 录制回放   - 把你自己的一串操作录下来, 之后一键自动重放
               录制自动合并: 连续移动只记一行"移动到终点",
               短按一下记一行"单击/按键", 长按保留按下/抬起
4. 自定义热键 - 5 个功能的开关热键都可以自己改
5. 按键音效   - 任意按键绑定 wav/mp3 音效, 按下即播放,
               新按下的键会打断正在播放的音效
6. 拟人化     - 总开关 + 间隔随机/坐标抖动/按键时长/移动轨迹
               四项仿真, 降低被游戏识别为脚本的概率
7. 换语言换皮肤 - 高级设置页里可以切换中英文和 6 套主题皮肤
                (窗口边框/标题栏也跟随主题变色)

【默认热键】(可以在「热键」页改成任意组合键)
F6 = 连点开关
F7 = 录制开关
F8 = 回放开关(回放中按 F8 会停止回放)
F9 = 键盘连按开关
F12 = 全部停止

【运行限制: 连点 / 连按 / 回放 都一样】
这三个页面里都有一个「运行选项」卡片, 三个选项在同一位置:
① 指定次数        - 跑够这么多次就自动停
② 无限循环        - 一直跑, 直到按热键停止
③ 运行时长 / 到点 - 左边填"时 分 秒", 右边会自动显示
                     "本地时间 + 这个时长"作为截止时刻;
                     反过来改右边的截止时刻, 左边的时长也会跟着变。
                     到了这个时刻就自动停(支持过夜挂机)。
提示: 时间格式为 年-月-日 时:分:秒, 例如 2026-08-15 23:30:00

【窗口置顶】
标题栏右上角、最小化按钮的左边有一个图钉图标,
点一下 = 窗口始终显示在最前面, 再点一下取消。
(若看不到这个图标, 可右键点击系统托盘里的本程序图标,
 菜单里同样有「窗口置顶」开关)

【快速上手: 自动连点】
1. 打开游戏/目标窗口
2. 在「鼠标连点」页设好间隔(默认 100 毫秒)
3. 切到游戏窗口, 按 F6 开始, 再按 F6 停止
   (或把鼠标停在要点的位置, 用"跟随鼠标位置"模式)

【游戏屏蔽了怎么办】
进「高级设置」页:
- 先试"拟人化"保持勾选(默认已勾)
- 无效再换"注入方式"为 SendMessage
- 还不行就装驱动模式(说明在该页下方)

【录制与编辑】
1. 按 F7 开始录制 → 做你的操作 → 按 F7 停止
2. 录制中列表会实时显示你的每个操作
3. 停止后可以:
   - 双击某一行 → 修改它到下一行的间隔时间
   - 在列表上点鼠标右键 → 编辑延迟/插入/删除/上移/下移
   - "添加事件" → 插入鼠标移动/点击/滚轮/按键
4. 按 F8 回放(可调速度; 运行限制在「运行选项」卡片里选
   指定次数/无限循环/运行时长或到点)
5. 保存/加载宏: 文件默认存放在本目录的 Macros 文件夹

【按键音效怎么用】
1. 打开「音效」页, 勾选"启用按键音效"
2. 场景: 「场景」下拉框 = 一套完整的音效绑定
   - 点"新建场景"输入名字(如 绘画), 会创建 Sounds\绘画 文件夹;
   - 每个场景有自己的一套按键绑定, 切换场景即整体换一套;
   - "添加绑定"选中的音效会自动复制进当前场景的文件夹;
   - 默认场景的音效文件直接放在 Sounds 文件夹
3. 点"添加绑定" → 按一个键(如 F5) → 选择音效文件
   (wav/mp3 均可)
4. 之后任何时候按下这个键就会播放音效;
   再按其它绑定了音效的键, 旧音效立刻停止换新的
   (程序启动时就会自动准备好, 不需要先"试听"一次才能响)
5. 试听: 双击列表某一行; 删除: 选中后点"删除绑定"
6. 音量: 「全局音效音量」是总音量, 「选中按键音量」是该键的
   相对音量, 实际响度 = 两者相乘。
   全局音效音量拉到 0 = 全部静音(单独调过音量的键也一样)
7. 按了没声音? 少数系统的 MCI 不支持播放 mp3, 把音效文件转成
   wav 格式再绑定即可(可用 ffmpeg: ffmpeg -i 音效.mp3 音效.wav);
   打开失败的原因会写进同目录的 log.txt

【热键怎么改】
「热键」页 → 点右侧按钮 → 弹出窗口后按你想要的
组合键(比如 Ctrl+K, 或 Ctrl+Q+W, 鼠标侧键、媒体键也行)
→ 全部松开 → 确认。改完自动保存, 下次打开还在。

【两个常见问题】
1. 杀毒软件报警/删文件:
   这类自动化工具容易被误报。请把本文件夹加入
   杀毒软件(卡巴斯基/360/Defender 等)的排除项。
2. 热键冲突: 某个热键按了没反应, 可能是被别的
   软件占用, 换一个组合键即可。

【多显示器提示】
本程序支持每显示器缩放: 窗口在两个不同缩放的
屏幕之间拖动时, 界面会自动按新屏幕重排。

【设置都在 config.json 里, 删掉它 = 恢复出厂设置】
