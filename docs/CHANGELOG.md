# 变更日志 Changelog

本项目版本号集中在 `src/VersionInfo.cs`（`Version` 常量），界面/关于/状态栏/发布脚本共用。

## v2.3 — 2026-08

全量安全审查与缺陷修复版本（详见 `docs/代码审查报告-2026-08-15.md`）。

**安全**
- config.json 视为不可信输入：软件控制程序白名单（绝对路径 + exe/lnk，bat/cmd/文档一律拒绝）、音效绑定纯文件名校验（防路径穿越）
- 按键音效 MCI 播放移出钩子回调（后台队列），防 UI 冻结与钩子被系统静默摘除；钩子回调 try/catch 兜底
- 日志：异步缓冲写入、消息换行转义（防日志行注入）、轮转改为 rename（不再截断其它实例的日志）

**修复**
- 引擎停止→快速重启动竞态（双线程并发注入/跨代卡键）——三引擎代际计数，退出前等待线程收尾
- 回放停止只补发最后一个按住键 → 按住状态线程局部化，停止时全部补发抬起
- 「运行到时刻」跨天判断错误（22:00 设 03:00 无法过夜）→ 目标时刻已过自动归到次日
- Interception 驱动回放触发自身热键/音效 → 回放期间抑制（「全部停止」例外始终可用）
- 副屏在主屏左侧/上方时录制回放坐标损坏 → 宏坐标允许负值 + 注入前钳制
- 热键捕获框误录：过滤注入按键/点击，点击对话框本身不再被录成"鼠标左键"
- 录制鼠标/键盘共用计时导致长按被误合并成单击 → 分设备计时
- 其它：滚轮 int.MinValue 溢出、热键钩子部分失败回滚+告警、静默启动首屏跨线程 UI 访问、音量标签与滑块不一致、引擎异常空吞（补日志）等

**体验/性能**
- 英文模式按钮文字溢出：标签条按语言动态配宽，按钮文字放不下自动缩字号，14 处按钮加宽
- 宏库列表按修改时间缓存（不再每次全量反序列化），超大文件跳过
- 测试点击移后台线程；跨屏拖动 DPI 重建加 500ms 冷却；退出时释放菜单/字体/驱动上下文等资源
- README 增加英文版与中英界面截图，发布包同步收录

## v2.0 — 2026-08

首个完整大版本，功能与工程化收尾。

**核心功能**
- 鼠标连点：固定间隔、固定坐标/跟随光标、次数限制、拟人化落点抖动
- 键盘连按：点按/按住两模式，支持下拉选择或**直接输入按键**（字母/数字/按键名）
- 录制回放：全局低级钩子录制、按键精灵式合并、虚拟列表实时刷新、事件编辑（延迟/插入/删除/上下移）、倍速循环回放
- 回放运行限制：**循环次数 / 运行分钟数 / 运行到系统时刻**三种停止条件
- 宏库页：已存宏列表（▶ 快速触发、重命名、创建副本、删除）+ **软件控制**（回放开始/结束时自动启动程序）
- 全局热键：5 个功能开关，任意组合键（多键组合、鼠标侧键、媒体键）
- 按键音效：单键/组合键绑定 wav/mp3，覆盖式播放，全局与单键音量
- 拟人化：高斯间隔、落点抖动漂移、随机按键时长、贝塞尔轨迹（Fitts 时长）
- 三套注入方式：SendInput / SendMessage / Interception 驱动级
- 6 套主题 + 中英双语 + 每显示器 DPI 感知 + 界面动效（悬停/按压/标签过渡，可关闭）

**工程化**
- 新增 `Log.cs` 文件日志（log.txt，自动轮转 2MB）
- 新增 `VersionInfo.cs` 集中版本号
- 新增 `tests/` 单元测试（Hotkey 解析/序列化、AppConfig 序列化往返）
- 新增 `publish.bat` 一键打包发布
- 配置结构版本号 `ConfigVersion` 与迁移钩子

**修复**
- 修复 config.json 从未真正加载的隐藏 bug（`JavaScriptSerializer` 字典键必须字符串）
- 修复录制回放事件选中后无法编辑/删除
- 修复音效全局音量错误联动选中按键音量
- 修复数字输入框无法键盘输入
- Interception 驱动过滤器 try/finally 复位 + 串行锁，防止异常时整机键鼠被拦截
- 回放停止/结束时补发抬起，防止卡键
- 多处关窗/DPI 重建崩溃与线程安全加固
