# 变更日志 Changelog

本项目版本号集中在 `src/VersionInfo.cs`（`Version` 常量），界面/关于/状态栏/发布脚本共用。

## v2.5 — 2026-09

**修复**
- **2K/多显示器记录回放坐标偏移**：`SendInputMove` 按整个虚拟桌面归一化坐标，却漏了 `MOUSEEVENTF_VIRTUALDESK`，主显示器不在 (0,0)（副屏在主屏左侧/上方）时实际落到主屏坐标系 → 回放整体“跑偏”（2K 副屏录制后回放在主屏靠右）。补上该标志即按虚拟桌面映射
- **回放中按 F8 停不下来**：回放期间 `HotkeyManager.Suppress` 把 Play 热键一并抑制（驱动级注入无 INJECTED 标记时的自触发防护）——结果是开始回放后连按 F8 也停不掉，只能强杀进程。现在「回放开关(F8)」与「全部停止(F12)」在抑制期间始终放行（录制端已排除热键键，基本不会自触发）
- 钩子回调整体 try/catch 兜底（`HotkeyManager`/`MacroRecorder`）：托管异常穿越原生回调边界会终止进程，且异常时也要照常 `CallNextHookEx`，避免吞掉用户输入
- **按键音效开机后第一次按不响**：MCI 播放改由**一条常驻后台线程**串行执行（原来走 ThreadPool，MCI 的隐藏通知窗口/设备上下文会随线程退出而失效），启动时先在该线程上 `WarmUp()` 预热；`open` 失败会重试一次并把 MCI 错误码写进 `log.txt`（原来静默 return，无法排查）。「试听」也走同一条线程
- **全局音量拉到 0 仍出声**：原单键音量是「覆盖」全局，`SfxBindingVolumes` 里存过的键不受全局影响。现改为**全局音效音量 = 总音量**，实际响度 = 单键相对音量 × 全局音效音量，全局 0 = 全局静音（键单独设过音量也一样）；「全局音量」改名「全局音效音量」
- **录制回放页标题与控件重叠**：卡片标题画在卡片顶部 7~27px，原来「Record / Play」按钮在 y=22、「Playback Options」速度行在 y=18 → 都压在标题上。现在卡片内第一行统一从 y≥30 开始，速度行并入「Record / Play」卡片第二行，事件列表整体下移、间距放宽
- **输入框光标一直闪 / 后续数字误入上一个输入框**：点击卡片空白处、标签等非输入区域时让当前输入框失焦（等价于确认输入，数值照常保存），光标停止闪烁、后续按键不会再跑进上一个框

**新增 / 优化**
- **运行限制三选项**（鼠标连点 / 键盘连按 / 录制回放 三个页面同一控件、同一位置）：
  ① 指定次数 ② 无限循环 ③ 运行时长(时/分/秒) 或 运行到指定时刻 —— ③ 里“时长”与“截止时刻”**双向同步**：设 10 分钟即显示“本地时间 + 10 分钟”作为截止点；改截止时刻又反算出运行时长
- **键盘连按支持多键同时按下**：原“或直接输入按键”输入框改为「点击按键」按钮，点一下弹出捕获框，可捕获单个键或同时按下的多个键（如 `Shift+A`），捕获到的新键会替换按钮上显示的旧键；单键下拉框保留
- **「窗口置顶」由复选框改为图钉图标，画在标题栏非客户区、最小化按钮左侧**（`WM_NCPAINT` 自绘 + `WM_NCHITTEST` 命中，`SM_CXSIZE` 定位）；状态用高亮表示、悬停显示提示。托盘右键菜单也加了「窗口置顶」开关作为备用入口
- **连点/连按设置即时保存**：间隔、按键、坐标、模式、运行限制等改动立即写入 `config.json`（250ms 节流合并，拖动滑块/按住箭头不会每次变化都落盘），退出/崩溃后仍记住上次设置
- **按键音效场景化**：每个场景 = `Sounds` 下的一个子文件夹 + 自己的一组按键绑定。音效页「场景」下拉框切换场景（整体换一套绑定），「新建场景」输入名字即创建（如 `绘画` → `Sounds\绘画\`）；添加绑定时音效文件自动复制进当前场景文件夹；旧配置的全部绑定迁移进「默认」场景
- `HotkeyDown/Up` 同步补发扩展键标记（方向键/Insert 等在组合键里也能正确注入）

**发布前审查修复（v2.5 首发前）**
- **捕获弹窗里按 F8/F12 误触发功能**：F8 放行名单漏进了「点击按键」/热键改绑的捕获模式——捕获连按键想按 F8 时会真的启动/停止回放。新增独立的捕获暂停标志，捕获期间全部热键（含 F8/F12）暂停
- **「运行到指定时刻」跨重启漂移**：用户设「明天 08:00」关闭程序后，重开截止点变成「现在+旧时长」。现在保存「以截止时刻为准」标志，重启后采纳保存的绝对时刻（已过期顺延到下一个该时刻，过夜挂机语义不变）
- **时长清零后启动仍跑 10 分钟**：改为 0 秒 = 立即停止，与界面显示一致
- **连按捕获鼠标键静默无效**：捕获框能捕鼠标键但键盘注入无法表达 → 启动前拒绝并提示
- 修复音效首次 open 失败但重试成功时仍写 WARN 的日志噪音；修复 Lang 重复键导致的新文案不生效；迁移测试断言全部重写为有区分力的用例
- 音效打开失败(266)时日志给出「转 wav」提示——部分系统 MCI 无法加载 mp3 设备驱动，wav 经 waveaudio 设备稳定播放
- **移除按钮键盘焦点虚线环**：启动后窗口尚未收到鼠标活动时，系统焦点提示状态为「显示」，拿到初始键盘焦点的按钮会画出黑色虚线框（鼠标移上去才消失）——工具类软件不需要键盘焦点环
- 键盘连按页「按键」标签与输入框对齐（y+4 与其它页同规范）

## v2.3 — 2026-08

全量安全审查与缺陷修复版本（详见 `docs/代码审查报告-2026-08-15.md`）。

**安全**
- config.json 视为不可信输入：软件控制程序白名单（绝对路径 + exe/lnk，bat/cmd/文档一律拒绝）、音效绑定纯文件名校验（防路径穿越）
- 按键音效 MCI 播放移出钩子回调（后台队列），防 UI 冻结与钩子被系统静默摘除；钩子回调 try/catch 兜底
- 日志：异步缓冲写入、消息换行转义（防日志行注入）、轮转改为 rename（不再截断其它实例的日志）

**修复**
- 引擎停止→快速重启动竞态（双线程并发注入/跨代卡键）——三引擎代际计数，退出前等待线程收尾
- 回放停止只补发最后一个按住键 → 按住状态线程局部化，停止时全部补发抬起
- 「运行到时刻」跨天判断错误（22:00 设 03:00 无法过夜）→ 目标时刻已过自动归到次日
- Interception 驱动回放触发自身热键/音效 → 回放期间抑制（「全部停止」例外始终可用）
- 副屏在主屏左侧/上方时录制回放坐标损坏 → 宏坐标允许负值 + 注入前钳制
- 热键捕获框误录：过滤注入按键/点击，点击对话框本身不再被录成"鼠标左键"
- 录制鼠标/键盘共用计时导致长按被误合并成单击 → 分设备计时
- 其它：滚轮 int.MinValue 溢出、热键钩子部分失败回滚+告警、静默启动首屏跨线程 UI 访问、音量标签与滑块不一致、引擎异常空吞（补日志）等

**体验/性能**
- 英文模式按钮文字溢出：标签条按语言动态配宽，按钮文字放不下自动缩字号，14 处按钮加宽
- 宏库列表按修改时间缓存（不再每次全量反序列化），超大文件跳过
- 测试点击移后台线程；跨屏拖动 DPI 重建加 500ms 冷却；退出时释放菜单/字体/驱动上下文等资源
- README 增加英文版与中英界面截图，发布包同步收录

**新增**
- 鼠标连点 / 键盘连按支持**运行时长倒计时**与**运行到系统时刻**两种停止条件（与回放一致；到点/到时自动停止，跨天判定支持过夜挂机）

**修复**

## v2.0 — 2026-08

首个完整大版本，功能与工程化收尾。

**核心功能**
- 鼠标连点：固定间隔、固定坐标/跟随光标、次数限制、拟人化落点抖动
- 键盘连按：点按/按住两模式，支持下拉选择或**直接输入按键**（字母/数字/按键名）
- 录制回放：全局低级钩子录制、按键精灵式合并、虚拟列表实时刷新、事件编辑（延迟/插入/删除/上下移）、倍速循环回放
- 回放运行限制：**循环次数 / 运行分钟数 / 运行到系统时刻**三种停止条件
- 宏库页：已存宏列表（▶ 快速触发、重命名、创建副本、删除）+ **软件控制**（回放开始/结束时自动启动程序）
- 全局热键：5 个功能开关，任意组合键（多键组合、鼠标侧键、媒体键）
- 按键音效：单键/组合键绑定 wav/mp3，覆盖式播放，全局与单键音量
- 拟人化：高斯间隔、落点抖动漂移、随机按键时长、贝塞尔轨迹（Fitts 时长）
- 三套注入方式：SendInput / SendMessage / Interception 驱动级
- 6 套主题 + 中英双语 + 每显示器 DPI 感知 + 界面动效（悬停/按压/标签过渡，可关闭）

**工程化**
- 新增 `Log.cs` 文件日志（log.txt，自动轮转 2MB）
- 新增 `VersionInfo.cs` 集中版本号
- 新增 `tests/` 单元测试（Hotkey 解析/序列化、AppConfig 序列化往返）
- 新增 `publish.bat` 一键打包发布
- 配置结构版本号 `ConfigVersion` 与迁移钩子

**修复**
- 修复 config.json 从未真正加载的隐藏 bug（`JavaScriptSerializer` 字典键必须字符串）
- 修复录制回放事件选中后无法编辑/删除
- 修复音效全局音量错误联动选中按键音量
- 修复数字输入框无法键盘输入
- Interception 驱动过滤器 try/finally 复位 + 串行锁，防止异常时整机键鼠被拦截
- 回放停止/结束时补发抬起，防止卡键
- 多处关窗/DPI 重建崩溃与线程安全加固
